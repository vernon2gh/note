## 简介

像给5岁的孩子解释一个话题，以HTML形式。

## 安装

```bash
$ mkdir -p skills/eli5
$ cd skills/eli5
$ wget https://raw.githubusercontent.com/anthropics/claude-plugins-community/refs/heads/main/eli5/skills/eli5/SKILL.md
```

## 如何使用？

```bash
$ pi
> /skill:eli5 xxx     ## 进行提问即可
```
