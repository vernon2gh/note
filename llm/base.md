## 基础概念

### 权重（weights）

训练完成后学到的**固定参数**，是 GGUF 文件的 ~99% 内容。推理时参与 `y = Wx` 运算，本身只读不变。

- 关键性质：**只读 + 磁盘上永远有备份** -> 所以适合 mmap 成文件页
- 例子：`tok_embd`、`blk.N.attn_q`、`blk.N.ffn_gate_inp`（router）、`blk.N.ffn_*_exps`（专家）

### 张量（tensor）

张量 = 一个 N 维数组 + 描述它的元数据。是标量、向量、矩阵的统一推广：

```
0 维：标量      1 维：向量       2 维：矩阵        3 维+：张量
   ●            ●—●—●—●          ┌───────┐         +---------+
   3            1 2 3 4          │1  2  3│        /         /│
                                 │4  5  6│       +---------+ |
                                                 |         | |
                                                 |         | /
                                                 +---------+/
```

前面说的权重，在代码里每一个都是张量


| | 权重张量 | 激活张量 |
|---|---|---|
| 来源 | GGUF 文件加载 | 推理时 `权重×输入` 临时算出 |
| 生命周期 | 常驻 | 用完即弃 |
| 内存类型 | 文件页 / VRAM | 匿名页 / VRAM |


## 加载阶段

```
GGUF 文件 (metadata + 词表 + 权重)
        |
        +--------------+-----------------+
        v              v                 v
   权重           KV cache         计算 buffer
   CPU：文件页    CPU: 匿名页      CPU: 匿名页
   GPU：VRAM      GPU: VRAM        GPU: VRAM
```


| 组成部分 | 默认内存类型 | 备注 |
|---|---|---|
| 权重 | **文件页** | 可回收的干净页 |
| CPU：KV cache | **匿名页** | 推理新产生的数据，磁盘没有 |
| CPU：计算 buffer | **匿名页** | worst-case 预留 |
| logits/embd 输出 | **匿名页** | |
| GPU 上的一切（权重/KV/compute） | **VRAM** | 不属于文件页/匿名页分类 |


## MoE 核心机制

### MoE 权重


| 权重 | 形状 | 体量 |
|---|---|---|
| Router 权重 | `[n_embd, n_expert]` 2 维 | 极小 |
| 专家权重  | `[in, out, n_expert]` 3 维张量 | **~93% 体积** |


### 两阶段执行

```
【阶段1: 只碰 router 权重】--------------> 专家编号 + 混合权重
【阶段2: 此刻才碰专家张量】--------------> 对选中专家输出
```

- router 先跑完才知道加载谁 -> 一切按需加载机制都插在两个阶段之间
- 选中的专家完整使用（专家内部是稠密矩阵乘，无二次稀疏）；未选中的一个字节都不读
- 一次前向的加载量 = 各 token 选中专家的**并集**

### KV cache

- 每层的 K/V 按 `n_ctx` 一次性预分配（不是按需增长）
- 是推理新产生的数据 -> CPU 侧为匿名页，GPU 侧为 VRAM
- MoE 稀疏的是 FFN，KV cache 与稠密模型无异

## 完整流程：prompt -> 文本

```
  "你好"
    │
    ▼ ① tokenizer 切词                       [CPU 纯计算]
  token ids
    │
    ▼ ② tok_embd 查表 → 向量 x              【权重: 文件页 / VRAM】
    │
    ▼ ③ 循环 N 层:
    │   ┌──────────────────────────────────────────────────────────┐
    │   │ attention:                                               │
    │   │   Q K V 投影           【权重: 文件页 / VRAM】           │
    │   │   读写历史 K V         【KV cache: 匿名页 / VRAM】       │
    │   │                                                          │
    │   │ MoE FFN:                                                 │
    │   │   router 打分选8个专家 【router权重: 文件页 / VRAM】     │
    │   │   选中专家加载计算     【专家权重: 文件页/ VRAM】│
    │   │                                                          │
    │   │ 中间结果 tmp           【激活: 计算 buffer, 匿名页/VRAM】│
    │   └──────────────────────────────────────────────────────────┘
    │
    ▼ ④ × output.weight → logits (词表上每个词的分数)
    │                             【权重: 文件页/VRAM】
    │                             【logits: 匿名页】
    │
    ▼ ⑤ sampler 按概率抽 1 个 token id                    [CPU]
    │
    ▼ ⑥ 查词表 → "今"                                     [CPU]
    │
    └────── "今" 拼回输入, 回到 ② ，每圈出一个字，直到结束符
```
